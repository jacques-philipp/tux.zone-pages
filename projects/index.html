🛠️ Projects#

Welcome to the showcase of weird and wonderful things I’ve built.
Some are serious tools. Some are just revenge projects against YAML. All are proudly open source.

🚨 AlertRat#

Prometheus + Grafana + Alertmanager in a namespace.
A GitOps-friendly stack for OpenShift that lets you run your own alerting without touching the sacred openshift-monitoring. Because sometimes you just want to scream into your own Alertmanager.

  • 🔗 View on GitHub
  • 🧠 Technologies: OpenShift, Prometheus, Grafana, Alertmanager, GitOps

🧰 Tux Tools#

A multi-tool container with all the boring-but-necessary things you need when debugging weird pods, volumes, or Ingress behavior.
Because kubectl exec deserves better friends.

  • 🔗 View on GitHub
  • 🐧 Includes: curl, dig, netcat, bash, jq, sass, sarcasm

🧾 OpenShift Health Reporter#

A cluster-friendly CronJob that checks certificates, nodes, and core operators. Outputs a friendly health summary with emojis because monitoring doesn’t have to be ugly.

  • 🔗 View on GitHub
  • 📬 Sends reports to MS Teams or email

🔒 Overcompensator#

Documentation and automation for my ridiculously overbuilt home lab setup, running VLANs, WireGuard, KVM, and more. Named after how insecure I am about my switch config.

  • 🔗 View on GitHub
  • 🌱 Powered by OpenWRT, Proxmox, dnsmasq, and caffeine
